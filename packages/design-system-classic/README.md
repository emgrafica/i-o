# Getting Started with i-o StoryBook

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Install 

### `npm i git+https://github.dxc.com/MWA/io-storybook.git`

## For development at local environment
Clone this repo to your local.

**For starting storybook**
### `npm run storybook`



**For build component**
### `npm run build`
It will bundle all components at export at ./build




**Link your project to Storybook components**
### `npm link {your local directory}`

It will be link ./build folder to your package.




**Useage:**
### `import { IoCard} from '@i-o/design-system-classic'`

## Public storybook:
### `npm run build-storybook`

The bundle files will contain at ./storybook-static
